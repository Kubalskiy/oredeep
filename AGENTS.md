# Ore Deep — контекст проекта для Cursor AI

> Файл-контекст для ИИ-ассистента (Cursor). Idle/incremental RPG про дварфа-шахтёра.
> Тематическая адаптация idle-прототипа. Всё описание — источник правды для реализации.
> Термины даны в сеттинге «Ore Deep», в скобках — исходная механика прототипа.

---

## 1. Обзор

- **Жанр:** mobile idle / incremental RPG, портрет.
- **Core loop:** авто-бой PvE → золото + сундук → прокачка (экипировка, навыки, питомцы, бороды, таверна) → следующая штольня → повтор. Оффлайн-доход и таймеры обязательны.
- **Стек (предложение, уточнить у пользователя):** TypeScript. UI — любой из React / Phaser / Cocos. Логика игры отделена от рендера: чистый `core/` (симуляция, экономика, гача) + `ui/` (экраны). Персист состояния локально + серверная синхронизация PvP/таверны.
- **Обязательно:** детерминированная боевая симуляция (для server-side PvP), сидируемый RNG для гачи, целочисленная/BigInt-безопасная экономика (значения до B+).

## 2. Ресурсы и валюты

| key | Ore Deep | тип | назначение |
|-----|----------|-----|------------|
| `gold` | Золото | soft | апгрейд сундуков, покупки |
| `gems` | Самоцветы | hard | крафт, аватары, ускорения |
| `chest` | Сундук | gear gacha | 1 сундук = 1 предмет экипировки |
| `barrel` | Бочка | skill gacha | содержит N карт навыков |
| `key` | Ключ | consumable | бесплатное открытие бочек |
| `egg` | Яйцо | consumable | крутка питомца |
| `comb` | Расчёска | consumable | крутка бороды |
| `ale` | Эль | upgrade | апгрейд навыков |
| `artifact` | Артефакт | collectible | бонусы + дарение в таверне |

Форматирование чисел: `1e3=K, 1e6=M, 1e9=B` (2 знака). Проценты — целые. HP — с разделителями (`8,500`).

## 3. Модель состояния (source of truth)

```ts
type Rarity =
  | 'common' | 'rare' | 'epic' | 'legendary'
  | 'exotic' | 'mythic' | 'ascended' | 'cosmic'; // экипировка = все 8

type GearSlot =
  | 'helmet'   // Каска
  | 'gloves'   // Перчатки
  | 'pickaxe'  // Кирка
  | 'lantern'  // Фонарь
  | 'pants'    // Штаны
  | 'boots'    // Сапоги
  | 'belt'     // Пояс
  | 'robe';    // Роба

interface GameState {
  player: {
    name: string;
    avatarId: string;
    profileRarity: 'common'|'rare'|'epic'|'legendary';
    gold: bigint; gems: number;
  };
  resources: { chest:number; barrel:number; key:number; egg:number; comb:number; ale:number };
  run: { mine: string /* "45-19" */; difficulty: string /* "БРУТАЛЬНАЯ" */; stage: number };

  stats: { atk:number; def:number; str:number; crit:number; combo:number;
           luck:number; speed:number; dodge:number; hp:number; stamina:number; regen:number };

  gear: Record<GearSlot, GearItem | null>;
  chestLevel: number;                 // уровень гача-сундука
  autoRoll: { on:boolean; keepRarity:Rarity; queue:GearItem[] };

  pets:  { collection: Pet[]; equipped: (string|null)[] /* слотов 1..3 */ };
  beards:{ collection: Beard[]; equippedId: string|null };
  skills: SkillCard[];
  artifacts: { owned:Record<string,number>; sets: ArtifactSet[] };

  combat: {
    enemy: { name:string; hp:number; hpMax:number };
    auto: boolean;
    energy: { cur:number; max:number; regenTimer:number };
  };
  timers: { bonusChest:number; powerUpgrade:number; boost2x:number }; // секунды
  loot: { pendingGold:bigint; pendingChests:number; passiveStartedAt:number };

  prestige: { level:number; bankedPower:number };
  tavern: TavernState | null;
  pvp: { trophies:number; rank:number; dailyBattlesLeft:number };
  dailyQuests: Quest[];
  badges: { quests:boolean; skills:boolean };
}

interface GearItem { slot:GearSlot; rarity:Rarity; level:number; power:number; }
interface Pet   { id:string; family:string; rarity:Rarity; count:number; }
interface Beard { id:string; type:string; rarity:Rarity; length:number; /* вместо level */ }
interface SkillCard { id:string; level:number; copies:number; }
```

## 5. Системы — правила реализации

### 5.1 Экипировка + сундуки (`equipment`)
- Открыть сундук → `rollGear(chestLevel)` → предмет. Игрок: **Надеть** (уничтожает предыдущий в слоте) или **Продать** (→ `gold`).
- Апгрейд сундука за `gold`, по таймеру; уровень меняет drop-таблицу (↑ шанс редких).
- **Auto Roll:** 1 сундук / 2 сек; `< keepRarity` → автопродажа; `>= keepRarity` → `queue` для ручного решения.

### 5.2 Питомцы (`pets`)
- Roll за `egg`; pity: шанс редкого растёт с числом круток.
- **Merge:** 3 одинаковых → 1 **случайный** питомец следующего rarity (не тот же). На cosmic — заблокирован.
- **Crafting:** открыт после 3 legendary; рецепт = конкретные питомцы + `gems`; единственный путь к exotic+.
- Эффекты: damage/hit; DPS; passive ATK для семьи; Bleed (DoT); Shock (DoT + −DEF врага); Splash (DoT + −atk speed врага).
- Пул: common `goblin_dog, slime, spider, rat, bat`; rare `imp, mushroom_cat, skull`; epic `manticore, wyvern, beholder`; legendary `mimic, pseudodragon`. **Mimic:** +шанс получить 2 сундука вместо 1.
- Слоты питомца: 1 базовый; epic-mimic открывает 2-й; legendary — все 3.

### 5.3 Бороды (`beards`)  — ex-«девушки»
- Roll за `comb`; копия стакается и увеличивает **длину** (вместо уровня).
- **Merge:** целевая борода поглощает материалы (редкость ≤ целевой) → рост длины.
- Восхождение: legendary нужной длины + `comb` + `gems` → tier up.
- Бонусы к персонажу: HP, ATK, DEF, Crit, Dodge, Combo, Stamina, Regen/debuff resist.
- Типы (пример): Медная, Каменная, Стальная, Золотая, Рунная.

### 5.4 Навыки + Эль (`skills`)
- Открыть бочку (`key` или `gems`) → skill card pull. Новая карта → навык Lv1; повтор → `copies++`.
- Когда `copies == level` → апгрейд за `ale`; уровень усиливает эффект.
- Навыки постоянны (работают всегда, не «экипируются»), дают глобальные мультипликаторы.

### 5.5 Артефакты (`artifacts`) — ex-«стикеры»
- Пак из 5 случайных за `gems` (в Рынке).
- В таверне: дарить дубликаты в чат; забрать может любой участник; дарение даёт Уважение.
- Сеты дают `bonusGems`/статы при заполнении (напр. «Собрано 7/27 → +125 самоцветов»).

### 5.6 Престиж (`prestige`)
- Вход: вся экипировка = `cosmic`.
- Сброс: `chest→1`, `gold→start`, экипировка уничтожается, `stage→1`.
- Сохраняется: навыки, бороды, питомцы, артефакты, таверна.
- Получает: постоянный `bankedPower`; множитель ×N (по уровню престижа) к HP/ATK/DEF на тренировках.

### 5.7 Бои PvE + пассив (`combat`)
- Авто-старт, враги друг за другом; симуляция считает удары до KO одной стороны.
- Победа → `gold` + `chest`; шанс доп. `key`/`egg`/`comb`.
- Параметры: Health, Attack, Defense, Dodge, Crit (×2 награда), Combo, Stamina (продлить combo), Attacks/sec, Regen.
- Пассив: оффлайн копит `gold` + `chest`, лимит **2 часа**; забор перезапускает таймер (`passiveStartedAt`).

### 5.8 PvP Арена (`pvp`) — адаптация
- Асинхронная (cloud stats, server-side result). **Механика:** два дварфа добывают бесконечную жилу; лимит **3 минуты**; больше добыл — победил; уставший останавливается.
- Выбор соперника из **3** кандидатов. Победа → трофеи (↑ таблица), поражение → −трофеи. Верх таблицы → новый ранг + награда. Дневной лимит боёв; выход = поражение.

### 5.9 Ежедневные квесты (`dailyQuests`)
- Checklist: выиграть обычные бои / PvP; прокачать навыки; открыть сундуки; провести застолья.
- Выполнение → жетоны → прогресс-бар; вехи выдают `key`, `egg`, `gems`, пак артефактов.

### 5.10 Таверна / гильдия (`tavern`) — ex-«зал»
- Создать/вступить; Уважение (Gym XP) из застолий, PvP-побед, квестов, дарения артефактов.
- **Застолья (тренировки):** повышают характеристику; могут дать паки артефактов, `key`, `comb`, `egg`, `gems`. Дольше → больше; досрочно за `gems`. Пассивный доход `ale`.
- 50 уровней таверны; апы дают всем `gems`. Чат с жертвованием артефактов. **Дебоши** (гильд-войны) — later, не реализовывать сейчас.

### 5.11 Штольни (`mines`) — особые бои
| id | reward | тип боя |
|----|--------|---------|
| `barnyard_brawl` | chest | несколько врагов, HP не восстанавливается |
| `muscle_mania` | gems | несколько врагов, HP не восстанавливается |
| `zookeeper` | egg | несколько врагов, HP не восстанавливается |
| `bouncer` | comb | один сильный враг |
| `show_fight` | ale | один сильный враг |
- 2 жетона на штольню/день; сила врага = сложность; награда растёт по **геометрической** формуле с уровнем.

### 5.12 Профиль (`profile`)
- Никнейм; аватар за `gems` → задаёт `profileRarity` и бонусы:
  - common: ×1.1 HP
  - rare: ×1.1 HP, ×1.1 ATK
  - epic: ×1.3 HP, ×1.2 ATK, +3% Crit, +1 слот тренировок, +1 слот питомца
  - legendary: ×3 HP, ×1.9 ATK, ×1.6 DEF, +8% Crit, +6% Dodge, +6% Combo, +2 слота тренировок, +2 слота питомца

### 5.13 Рынок (`market`) — 5 зон
1. Предложения (офферы со скидкой + отключение рекламы).
2. Артефакты (пак 5 шт).
3. Бочки с навыками (3 бочки, выше уровень → реже навыки).
4. Паки самоцветов (3, выгода +15% / +30% — **выводить абсолютную выгоду на карточке**).
5. Бесплатные предложения (2 раза/день: бесплатно + за рекламу, сброс ежедневно).

### 5.14 Реклама (Ad Reward)
Ускорение апгрейда сундука; ускорение PvE; обновление списка врагов PvP; бесплатные ресурсы в магазине; `gems`/`comb`/`ale`; жетоны Daily Quests; доп. валюта.

## 6. Правила поведения UI (инвариантны)

- Тап по врагу/герою → доп. урон + всплывающая цифра.
- Таймеры (`bonusChest`, `powerUpgrade`, `boost2x`) — обратный отсчёт в секундах; по нулю активируют действие.
- Бейджи: красная точка «!» = награда/новое; зелёная стрелка «↑» = доступен апгрейд (хватает ресурсов).
- Оффлайн-доход при входе: `incomePerHour × elapsed`, но не дольше лимита пассива.
- Хит-таргеты ≥ 44px; контраст текста ≥ 4.5:1.

## 7. Порядок реализации (предлагаемый бэклог)

1. `core/`: state store + персист + форматтеры чисел + сидируемый RNG.
2. Боевая симуляция PvE (детерминированная) + главный экран (зоны A–H).
3. Экипировка + сундуки + Auto Roll.
4. Навыки + бочки + Эль.
5. Питомцы (gacha + merge + craft).
6. Бороды (gacha + merge + восхождение).
7. Таймеры, энергия, пассивный лут, оффлайн-доход.
8. Ежедневные квесты + Рынок + реклама.
9. Таверна (гильдия) + артефакты + чат (нужен сервер).
10. Штольни (особые бои) + Профиль.
11. PvP-арена (нужен сервер, детерминированная реиграбельность).
12. Престиж.
